## 🎮 Gameplay & Features

- **Live Grand Prix Raceway**: Watch your custom cyber racer roar down the neon speedway with real-time distance driven by your typing pace!
- **Intelligent AI Ghost Competitors**: Race against 3 rival drivers calibrated to human speeds:
  - 🏎️ **Rookie Bot**: Steady 35–45 WPM pace.
  - ⚡ **Turbo Bot**: Aggressive 60–75 WPM speedster.
  - 🏆 **Nitro Champion Bot**: Fierce 85–100 WPM master racer.
- **Real-Time Speed & Precision Metrics**:
  - **Live WPM**: Continuous words-per-minute speedometer calculation.
  - **Accuracy Percentage**: Dynamic calculation penalizing mistyped keystrokes.
  - **Progress Bar & Checkered Flag**: Real-time position tracking and visual finish line celebration.
- **Curated Prompt Categories**: Switch between diverse quote libraries including *Tech & Cyberpunk*, *Classic Literature*, *Coding Trivia*, and *Proverb Quotes*.
- **Synthesized Web Audio Engine**: Realistic mechanical keyboard click/clack sound effects, pitch-scaled engine acceleration revs, tire screeches, error buzzer, and victory horn fanfare.
- **Persistent Local Records**: Saves your personal best WPM record, highest accuracy, and total grand prix trophies in browser `localStorage`.
- **Full Touch & Mobile Support**: On-screen focused input and smooth virtual touch typing support.

## ⌨️ Controls

| Control | Action |
| :--- | :--- |
| **Keyboard Typing** | Type the highlighted text prompt to accelerate your race car |
| **Spacebar** | Advance to next word |
| **Backspace** | Correct mistyped characters |
| **Pause (`Esc` / ⏸️ button)** | Pause / resume the race |
| **Sound (`🔊` button)** | Toggle audio synthesizer mute |
| **Next Race (`Enter` / 🏁)** | Launch a new grand prix with fresh text prompt |
